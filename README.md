# Dr.Hug — прототип сайта

Статический сайт на HTML, CSS и JavaScript. Главная страница — `index.html`; остальные страницы и ресурсы находятся в корне проекта и папке `assets/`. Сборка и установка зависимостей не требуются.

## Публикация на Vercel

1. Импортируйте этот репозиторий в Vercel.
2. Выберите **Framework Preset: Other**.
3. Оставьте корневую папку проекта (`.`) и пустую команду сборки.

Чат на сайте работает в демонстрационном режиме: сообщения не отправляются сотрудникам клиники. Для реального общения потребуется подключить сервис поддержки или серверную часть.
